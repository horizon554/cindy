# 鸿蒙手机首版任务与里程碑

建议将中国大陆手机的远程任务闭环作为第一版。M1 验证核心依赖，M2 交付内部可日用版，M3 交付带离线提醒的候选版，M4 完成发行验收。[技术选型与架构](README.md)

### M1a · 用手机模拟器在真实电脑上继续一条任务

联调前准备一台在线的 Cindy Desktop，用 CN 测试账号登录并允许远程访问。在电脑上打开一条无敏感内容的测试任务，记下任务标题及最后一条历史消息，供两端核对。实现阶段只需提供登录、选择电脑、打开已有任务和发送文本所需的最小界面。

| 步骤 | 操作 | 验收标准 |
| --- | --- | --- |
| 1. 安装和冷启动 | 在 DevEco Studio 选择已安装的 Phone 模拟器，运行 CN 开发包；结束应用进程，再从桌面图标启动。 | 两次都进入可交互的 Cindy 首屏。记录源码提交、包版本、IDE、SDK 和模拟器镜像版本。 |
| 2. 认证与网络 | 在模拟器应用内走实际开放的 CN 登录方式，完成所需验证码或回调。从应用连接目标 Relay；使用本机开发服务时先核对模拟器实际可达的地址。 | 登录完成后显示预期账号；应用与预期环境的 Relay 建立已认证连接。分别记录认证、Relay 的结果，便于区分登录失败和链路失败。 |
| 3. 找到电脑和历史 | 从设备列表选择准备好的真实 Desktop，通过 Device Link 打开测试任务。 | 设备名称、任务标题和最后一条历史消息与电脑一致。记录 Host 版本与实际传输路径；样本数据仅用于单页调试。 |
| 4. 收发一条消息 | 在模拟器发送带唯一标记的无副作用请求，例如“请分三段介绍四季，测试标记 M1a-01”。在两端观察同一任务。 | 电脑收到一条对应输入并开始一轮执行；模拟器在回复完成前能看到增量，结束后两端的最终回复和任务状态一致。 |
| 5. 断网后补齐 | 再发送一条带新标记的请求。电脑确认收到后，仅断开模拟器网络，让电脑继续到回复结束，再恢复模拟器网络。 | 应用恢复连接与订阅，自动补齐离线期间的内容。逐条核对两端消息顺序，电脑端该标记只有一条输入、一次执行，手机端无重复展示。 |
| 6. 重启后恢复 | 保留应用数据，结束模拟器中的 Cindy 进程，从桌面重新打开，回到同一任务。 | 有效登录得到恢复，可重新进入原电脑与任务；历史含刚才的两个标记和最终回复，重启没有重新提交输入。 |

**验收记录**按步骤填写通过、失败或待测。保留脱敏的两端截图或事件摘要，记录测试标记、实际连接路径与恢复结果；省略账号标识、验证码及令牌。

**进入 M2 的条件**为上述六步通过。随后可开发任务列表、消息与审批，M1b 真机复验最迟在 M2 内部可日用版验收前完成。若首批目标 Host 只能通过 Agent-Net 连接，提前验证该组合的真机传输。模拟器上的 Agent-Net 探索单独记录，华为推送端到端验收在 M3 进行。

- [ ] 接入设备目录、设备身份与 Device Link，打开真实 Host 上已有任务，发出一条文本并收到增量。分别记录真实 Host 版本、协商结果和收发路径。
- [ ] 并行验证 Agent-Net Rust 库、加密依赖、C ABI、UDP 与回调线程。与 Host 开关组合测试握手及断网恢复，明确可用路径与实际受限组合。

### M2 · 在手机完成一轮任务

三个开发批次已在模拟器实施，真实 CN Host 已通过新建、问答、停止与离线恢复联调。M1b 签名真机门槛待验。[M2 分批结果与验收记录](m2-validation.md)

- [x] 实现设备选择、任务列表与历史分页、新建或继续任务。绑定设备与账号，使用户能辨认任务在哪台电脑执行。
- [x] 接入草稿、文本发送、流式消息、工具状态与停止。发送已被 Host 接受但回执丢失时核对执行结果，避免重连触发重复执行。
- [x] 普通任务的用户消息和每轮最终回复保留操作与发送时间。可复制整条消息、通过系统面板分享文本，或从有消息锚点的回复分叉为新任务；更多菜单可复制消息链接或加入输入框。历史分页后按完整轮次判断，助手流式正文和工具行不显示操作条。明暗模式、历史滚动、分享面板和取消分叉已在模拟器验证，实际创建分叉与原草稿保留由集成测试覆盖。
- [x] 最后一条可编辑的用户消息在空闲时显示铅笔按钮，运行时从该消息的「更多 → 编辑」进入。输入框回填原文及附件，取消后恢复原草稿。发送时由电脑校验消息仍是最新一条，再回退并重发。回退回执丢失时可以取回编辑内容。[编辑入口验收记录](m2-validation.md#编辑最后一条用户消息)
- [x] 支持审批与问答卡片，验证决定被接受、拒绝、过期，以及另一端已完成交互时页面如何收敛。
- [x] 用 ArkData 保存历史与游标，恢复订阅后合并增量。用脱敏样本核对重复、乱序、未知类型和旧账号迟到响应。
- [ ] 在真机上核对中文组合输入、草稿恢复、长消息滚动锚点、键盘遮挡、系统返回和浅深色显示。

**完成条件**：用户创建任务、发送、回答一次交互并看到最终状态；另一次执行可停止。手机离线时能看已缓存历史，回来后与电脑端记录一致。切账号或撤权后，旧内容和旧审批不可访问。

### 首页伙伴分区

伙伴显示在任务首页的电脑与项目分组上方，已有群聊和单个伙伴按最近活动一起排序、计数，默认显示前 3 项。超过 3 项可展开或收起。搜索覆盖整份名单，支持伙伴名、群名和群成员名。每行第二行显示最近消息摘要；最近一条为语音记录时显示「语音通话」。在线伙伴使用电脑提供的摘要，仅在云端可见的伙伴从已有的一对一会话读取。群聊使用最多五位成员的组合头像，首页与群标题栏一致。电脑提供伙伴名单与会话绑定，Chat 服务提供已设主力电脑的云端伙伴。同一伙伴有主力电脑时只显示一次。

点击「伙伴」标题收起分区后，当前电脑范围内的群聊和单个伙伴按原排序横向排列。左右滑动可浏览全部头像，点头像进入对应会话。首页右上角「显示选项」中的「伙伴」提供「收起时显示头像」开关，默认开启。关闭后收起分区只显示标题和数量。收起状态与开关分别按本机账号保存。输入搜索词时展示匹配的纵向列表，清空后恢复搜索前的状态。

模拟器在浅色和深色下均验证了 9 个条目的横排顺序、滑到末项、分别从群聊和单个伙伴头像进入对应会话，以及清空搜索后的恢复。关闭开关并重启仍只显示标题和数量，重新开启立即恢复头像，展开后回到前 3 项。自动化测试另覆盖两个同名账号的偏好隔离。

点开在线伙伴会核对当前电脑上的正式会话，即使该会话不在首页最近任务中也可进入。有云端记录且主力电脑未列出该伙伴时，打开对应的一对一只读历史。模拟器验收覆盖真实名单的展开、返回和在线会话；主力电脑离线的只读入口另用隔离数据验证。

账号已加入的云端群按群 ID 打开，显示群成员署名和主时间线，可向前翻页；同一个群在电脑上有副本时只显示一次。隐藏、归档和已退出的云端群不计入首页。早期电脑本地群通过所属在线电脑打开，历史范围取决于电脑提供的记录。

点击群会话标题或右上角的设置按钮可查看群资料。页面显示群名、已填写的话题和介绍，以及带头像和名称的完整成员列表，可按名称搜索。群头像最多组合五人，成员列表按实际人数展示。返回会回到原群会话。群资料为只读。群会话的发送、附件和话题能力见下节。

鸿蒙模拟器使用已登录账号验证了混合计数、前三项、展开全部、按群名或成员名搜索、进入对应群与返回，以及明暗两种模式下的历史阅读。模拟器同时核对了群列表和标题栏的成员合成头像，以及文字伙伴和仅有语音通话记录的伙伴摘要。群资料在明暗两种模式下验证了标题与设置双入口、姓名搜索、无匹配提示和返回原会话；另验证了长名单滚动后继续显示头像，以及切换群后的资料归属。集成测试覆盖同名群和伙伴、同名成员、第六位成员的头像、电脑副本去重、电脑本地群资料与历史、云端分页、资料加载失败后重试及失去成员资格时清空会话和名单。

### 伙伴与群会话对齐 Android

| 项目 | 鸿蒙行为 |
| --- | --- |
| 1. 消息操作 | 在线伙伴在消息下提供复制、引用和更多，图片分享在更多里。普通任务沿用任务操作。云端只读单聊没有常驻操作栏。服务端群提供复制、引用、话题和图片分享，电脑本地群按其能力提供操作。 |
| 2. 时间 | 在线伙伴与群主时间线使用共用的五分钟分组规则，时间居中。云端只读单聊保留简洁历史。 |
| 3. 身份 | 在线伙伴使用伙伴头像，群消息使用成员头像和名称。同一伙伴在同一时间组内连续发言时收起重复身份，自身消息靠右。 |
| 4. 内容 | 会话展示 Markdown、引用块、任务卡状态与摘要。可访问的图片支持预览，其他附件显示文件入口。点击引用可定位已加载的原消息。 |
| 5. 云端历史 | 一对一历史按发送时间排序，同一时间按服务端序号排序。切回前台刷新最新一页，保留已加载的旧页。网络中断后有重试入口，失去访问权限清空历史。 |
| 6. 标题栏 | 群标题下显示成员数，活动执行期间显示运行状态。离线伙伴显示主力电脑状态，电脑目录中有名称时带上名称。 |
| 7. 群输入区与话题 | 可写群支持文字和提及成员，有附件能力时显示文件和相册。服务端群支持引用、查看话题历史和回复。主群和话题各保留当前草稿。发送结果未确认时重试复用原消息标识、引用快照和收件人。 |
