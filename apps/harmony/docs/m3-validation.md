# M3 鸿蒙客户端验收记录

2026-11-26，原生鸿蒙开发包已在 DevEco 手机模拟器验证附件、系统分享、离线语音和通知返回任务。真实 CN 账号经 Device Link 连接 Cindy Desktop。**M3 的云推送完成条件仍待验收**，目前缺少同一条任务从华为通道投递、手机收到通知到点击打开的完整记录。

## 行为与数据

- 通知入口识别账号和任务路径。实际打开前重新读取设备目录，向目标 Host 核对任务是否存在、隐藏或删除。即使目标不在当前任务列表首页，也可按 ID 验证。进入前保存原草稿，收到通知不会触发任务操作。
- 官方 CN 媒体服务签发私有 PUT 地址。客户端将用户选定的内容临时复制到应用私有缓存，计算 SHA-256，用文件流上传，再通过现有 Device Link 附件引用发送。账号凭据仅用于向 Cindy 申请上传地址。上传退出时清理临时文件，应用启动时清除上次意外退出留下的暂存文件。
- 每条输入最多 20 个附件。当前任务内，同一文件名和内容摘要复用已上传引用。上传应答丢失时，在签名有效期内重新选择同一文件会复用对象地址；过期后重新申请。草稿只持久化附件元数据与私有引用。已提交输入通过原客户端消息 ID 核对 Host 回执。Host 明确返回尚未收到时，可重试原输入；已移除的附件从原发送记录恢复，保留随后编辑的草稿。
- 系统分享先显示待接收内容。确认任务后才读取获准访问的外部文件、准备附件和合并文字。语音使用系统麦克风和本机中文离线识别，录音缓冲只在内存中。转写结果进入草稿，由用户点发送。
- 通知开关包含 Push Kit token 获取、更新、绑定和退出解绑。仅在现有设备通知注册接口同时确认注册成功和可投递后显示已开启。操作系统拒绝授权或签名无效时，界面显示原因。拒绝通知仍可通过前台任务页同步结果。

## 云推送与真机待验

1. **应用身份。** 当前开发包实际调用 Push Kit 返回 `1000900010`（应用身份不合法）。需要匹配的华为应用标识、Push Kit 权益、发行或联调签名，以及可安装该包的鸿蒙真机。[华为 Push Kit token 指南](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-guides/push-get-token/)
2. **服务端投递。** 本地可读的设备服务注册处理只接受 iOS/APNs 和 Android/FCM。客户端预留同一个 `PUT /api/device-link/push-token`，候选组合为 `platform=harmonyos`、`provider=huawei`、`appVariant=cn`，由服务端维护方共同确定。服务端须支持注册、轮换、解绑和真实华为投递，并在通知点击参数中带与注册一致的 `accountId` 和现有任务 `deepLink`。还需回归已发布的 APNs/FCM 通路。
3. **最终验收。** 用真实 Host 完成一次任务，关联同一条终态的服务端投递回执、签名真机锁屏收件和点击后打开的任务。再复测进程被系统回收、换账号、撤权，以及真人录音、打断和实际切网。另在模拟器锁屏期间试发过本地测试通知，未观察到可确认的锁屏卡片。通知中心点击通过的记录仅覆盖返回任务。完成真机投递验收后再核准 M3 的通知发行范围。
